# NFT Gift Scanner — Mini App MVP

## Что уже есть
- Mini App-интерфейс для Telegram.
- Разделы: каталог, поиск по модели, фильтр цены, избранное, источники.
- Сортировка по цене и фильтр по площадке.
- Избранное хранится в браузере телефона.
- Кнопка открытия Mini App в Telegram-боте.

## Важно
Это пока **интерфейс и демонстрационный MVP**, а не живой сканер. Карточки помечены как ДЕМО. Живые объявления, цены и контакты продавцов не подделываются: для них нужно подключить официальные API/разрешённые источники каждой площадки. У разных площадок могут быть ограничения и не у всех есть публичный API.

## 1. Опубликовать Mini App бесплатно через GitHub Pages
1. Создай репозиторий на GitHub, например `nft-gift-miniapp`.
2. Загрузи в корень репозитория файл `index.html`.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch, ветку `main`, папку `/ (root)`, сохрани.
5. Подожди публикацию. Получится HTTPS-адрес вида `https://ТВОЙ_ЛОГИН.github.io/nft-gift-miniapp/`.

## 2. Запустить бота в Termux
1. Замени свой `bot.py` этим файлом из архива.
2. В Termux задай переменные (подставь свои значения, токен никому не отправляй):
   `export BOT_TOKEN='НОВЫЙ_ТОКЕН'`
   `export WEBAPP_URL='https://ТВОЙ_ЛОГИН.github.io/nft-gift-miniapp/'`
3. Запусти: `python bot.py`
4. Открой бота и отправь `/start`.

Если токен уже задан в текущем Termux-сеансе, повторно задавать его не обязательно. После закрытия Termux переменные могут потребоваться снова.

## 3. Следующий этап — реальные данные
Для каждого источника нужно отдельно определить официальный API/разрешённый способ получения листингов, схему цены, валюту и ссылку на продавца. После этого подключается backend, который отдаёт Mini App проверенные объявления. Не вставляй токен бота в `index.html` или GitHub.
